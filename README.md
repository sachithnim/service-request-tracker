# Service Request Tracker

A compact, secure internal service request tracker built with a **Laravel** REST API and a **Next.js** frontend.

## Repository structure

| Folder | Description |
|---|---|
| [`backend/`](backend) | Laravel REST API (authentication, service requests, status workflow, tests) |
| [`frontend/`](frontend) | Next.js web application (login, request list, create form, detail view) |

> Setup instructions, API documentation and design decisions will be added as the project is completed.
